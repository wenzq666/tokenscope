# v0.4.0 发行版状态

2026-10-09。在既有 56 来源、参考计费、固定图表、北京时间与自动公开汇率基础上，加入逐来源本地路径管理，以及仅限 Cursor / TRAE 国际版的实验性手动凭据用量同步。最终 Release 构建十五组测试全部通过，原生运行、旧数据库升级和历史 USD 导出一致性验证通过。以下区分本轮实现、隔离运行验证、合成 fixture 与历史行为基线；本轮未使用真实 Cursor / TRAE 账户验证服务端连接。

## 发布产物

- 本轮文件为 [TokenScope.exe](../dist/TokenScope.exe)，Windows 10 / 11 x64，产品/文件版本 **0.4.0**；大小 **2,303,488 字节（约 2.30 MB）**，通过 10,000,000 字节门槛。
- SHA-256：`07375b7ec9bf21c0c01c27fad9597ef8d5a909145860f64d7b05a098973cab70`。
- [v0.4.0 构建报告](../dist/build-report.json) 记录本版大小、摘要和完整系统 DLL 清单；十五组测试与运行验证结果见下文。默认用户数据目录兼容此前版本。
- C++ / Win32，SQLite、yyjson、Zstandard 解压器、参考价目、38 个品牌图标及许可内嵌；静态 C++ 运行库，依赖检查仅包含 Windows 系统 DLL。
- 无需自带浏览器、.NET、Node 或 Python。当前发行文件未签名；尚需干净 Windows 10 / 11 分发验证。
- 默认用户数据在 `%LOCALAPPDATA%\TokenScope\`；数据库、公开价目与图标缓存独立于 EXE 体积，会随历史增长。

## 路径管理与实验性连接

- 全部 56 来源在设置逐项显示本地候选文件/目录，以及每条“已发现 / 未发现”；无用量或路径缺失也保留配置卡片，但不会在用量排行生成占位软件。
- 点击路径或“更改路径”进入原生完整路径编辑/文件/文件夹选择；每家支持恢复默认。自定义位置独占替代默认候选，配置位置缺失时不回退扫描其他默认路径。修改和恢复仅影响后续读取，不删除已入库历史。
- 原有 ANSI `settings.ini` 原子升级为 UTF-16LE，保留未识别配置节，支持 Unicode 路径重启回读；旧导入配置迁移后不会恢复成重复来源。路径保存失败时回滚本次选中位置，数据目录在启动时解析为绝对路径。
- 只有 `cursor`、`trae-code` 可手动提供凭据并调用用量同步；这是实验性的私有 Dashboard 接口，不是官方 OAuth，也不是所有智能体通用授权。其他来源提供格式/接入说明和实际导入；Copilot 等遥测来源仍需正确启用并落盘真实计量。
- 不自动提取浏览器 Cookie。主动输入的凭据使用当前 Windows 用户 DPAPI 加密，独立保存在本机 `connections/<source>/credential.bin`；不写入用量数据库、诊断或 CSV。解除连接移除本机凭据，已入库用量保留。
- 凭据已保存、同步中、本次成功、失败、授权过期分别展示。保存成功不是账户已验证；只有实际完整分页同步成功才发布缓存，随后按原有解析、实际时间、模型身份和去重规则入库。当前默认请求最近 30 天，不宣称完整账户历史。
- 连接状态摘要仅保存在运行内存，不写入 `settings.ini`。重启后能解密已有凭据时回到“已保存，待验证”，用户点击“同步”才重新读取远端；目前没有后台远端自动同步。
- 有效空结果可以表示同步成功，仍不生成零用量软件；仅有费用/Credits 没有 Token 的数据不伪造计量。认证失败、网络失败、分页不完整或取消不会覆盖旧缓存，已有真实用量继续可查。

连接接口、限制和测试依据见 [账户连接说明](connections.md)。连接实现及 fixture 验证不等于已经用所有真实账户成功同步；真实账户与版本覆盖需由相应账户实际验证。

| 能力 | 当前行为 |
| --- | --- |

| 计费口径 | 缓存读取、5 分钟 / 1 小时写入、推理子集及整请求长上下文档位；USD 定点运算，CNY 只作显示换算 |
| 价格优先与历史 | 精确身份手动规则优先用于未来和未定价记录；历史已选价目固定，流式增长仍使用原价目，刷新不会改写旧价格 |
| 未知 | 模型、价格或分项不足时保持未知；套餐 / Credits 不视作免费，API 估算不等于实际订阅扣款 |

| 分桶与排行 | 普通输入、缓存读取、缓存写入、普通输出、推理、未分类互斥；软件与模型展示占比和价格来源，零用量 / 未使用软件不占行 |
| 托盘 | 没有独立面板；保留图标、今日悬停、打开 / 刷新 / 暂停 / 设置 / 退出，关闭主窗口隐藏 |
| 时间显示 | 主窗口与托盘更新时间显式 UTC+8 北京时间，中文日期 / 时分秒；跨日、跨年和非法时间均验证，不回显原始 ISO 字符串 |
| 自动汇率 | 未设置手动值时获取 Frankfurter / ECB USD/CNY 最新公布日价，显示来源和公布日期；每日异步检查，失败限频重试、保留缓存，无值不猜测 |
| 来源设置 | 56 入口逐候选路径与存在状态、自定义独占替代/恢复、动态高度长路径；仅支持的两种来源显示凭据连接动作，其他显示接入说明 |
| 保留能力 | 今日、近 7 天、本月、全部；软件内不同模型逐行；USD / CNY、手动汇率优先且空 / 0 恢复自动、图表颜色、CSV 导出 |

模型 ID 原样显示，计价查找的有限别名归一化不重命名统计。参考项目部分缓存和档位处理、过时 Composer Fast 费率未照搬，依据和归属见 [参考审计](tokens-reference.md) 与 [计费口径](pricing-reference.md)。

Codex / Claude Code 采用持久文件偏移检查点，其他适配器通过持久元数据指纹（包含 SQLite WAL）跳过未变化来源，有变化才受限重读并按稳定身份去重。每 15 秒只检查本地来源文件，不等于全盘扫描或远端账户同步，也不表示每个来源都已实现逐文件偏移增量。
