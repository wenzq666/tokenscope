# Tokens.ci 参考记录

2026-10-08 只读参考 [Tokens.ci](https://tokens.ci/) 的公开用量页面，借鉴其信息布局。此记录不包含个人主页地址或账号统计；未在网页上执行交互，也未上传本机日志。

可借鉴的展示方式：

1. 年度贡献热力图及月份、周内日期刻度；每日可查看软件和模型明细。当前预览采用随宽度扩展日期范围、最多一年、保持小方格的设计，填满横向空间。
2. Token 分类展示输入、输出、缓存读取、缓存写入和推理。建议后续细化；来源适配要明确包含关系，不能把已包含在输入或输出中的缓存、推理再次累加。
3. 软件下模型显示占比；独立模型表可按费用和 Token 分别排序。建议后续加入当前的软件分组列表，以便比较模型的数量消耗与成本贡献。
4. 活跃天数、最高消耗日等历史摘要可作为后续可选项；总览继续优先服务用量与成本查询。

页面的公开排行、分享、嵌入、设备上传与 3D 图表暂不纳入本地托盘产品设计。其显示金额和模型身份只作为该公开页面的展示，不作为本产品已支持模型或价格的依据。

这是开发前的界面参考记录，演示数字不代表当前接入能力。最新实现范围见 [接入覆盖](../support-coverage.md)；第三方个人页面的 HTML 快照仅保留在本地，不纳入公开仓库或发行包。
