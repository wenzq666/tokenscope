# TokenScope — Windows 智能体用量看板设计稿

版本：v16 · 2026-10-09。状态：v0.4.0 原生开发版，新增全部 56 来源的逐候选路径显示、自定义独占替代/恢复，以及仅 Cursor / TRAE 国际版的实验性手动凭据用量同步。北京时间、自动公开汇率、API 估价与固定图表继续保留；最终构建与连接实测范围以开发状态为准，未完成的完整设计目标继续保留。

## 1. 已确认需求

1. 看板、软件用量、模型用量和托盘悬停摘要只统计已有有效用量的软件。未接入不出现；首次取得有效用量后自动出现。所选日期/范围没有用量的软件也不占行。
2. 国产智能体纳入接入规划，优先 TRAE、WorkBuddy、DeepSeek Harness；同时考虑 CodeBuddy、Qoder、Qwen Code、Kimi Code CLI 等同类工具。既有 Codex、Claude Code、Cursor、OpenCode 等候选保留。
3. 按软件分组直接列表展示实际模型，每个模型单独一行显示 Token 和预估费用，默认展开；保留软件小计，可继续下钻，也可跨软件按模型汇总。
4. 设置可选美元 USD / 人民币 CNY，全局统一费用显示。
5. 点选热力图或趋势图中的日期，下方软件用量同步显示这一天，模型明细继承相同日期。
6. 设置可分别调整热力图、趋势图颜色，支持恢复系统默认。
7. 用量总览时间范围增加“全部”，汇总所有已采集历史用量；软件分组、模型明细和预估费用使用相同范围。
8. 软件用量分组使用对应智能体的品牌图标替换首字母；总览和软件页保留“图标 + 软件名”。托盘使用应用自身图标及简短文字摘要。
9. 图表切换顺序为“趋势图 → 热力图”，首次打开默认趋势图；热力图采用类似 GitHub 的紧凑小方格。
10. 热力图用小方格横向铺满可用区域，宽窗口展示更长历史（最多最近一年），窄窗口缩短显示范围；未采集时段有独立状态。
11. 《盘点智能体软件和模型》中全部产品、平台和模型家族纳入必须覆盖的接入目标；加上原有清单，保留最初 26 个产品 / 平台与 12 个模型家族。v0.3 合并 tokens 参考客户端后共 56 个来源入口；入口不是模型数量，也不是本机已采集软件数，详见 [接入覆盖设计](support-coverage.md)。
12. 未采集日期只展示空白小方格，去掉点纹；每次启动先展示趋势图，不恢复上次的热力图选择。
13. 加入联网发现与更新：查询新智能体的官网、图标、模型信息和用量来源，更新软件 / 模型目录、价格与适配器；具体流程见 [联网发现与更新设计](online-discovery.md)。联网发现不等于已接入，仍须取得真实有效用量后才进入总览。
14. 产品保持用量统计工具定位，Windows 便携版单个 EXE 以不超过 10,000,000 字节为发布目标；采用轻量原生技术，真实大小须编译验证。运行产生的数据库与缓存另行管理，详见 [开发准备与体积计划](development-plan.md)。
15. 放弃独立托盘面板，保留托盘图标、悬停提示、打开主窗口及右键菜单；关闭主窗口继续后台统计。
16. 热力图固定截至今天。点选历史日只更新选中框、当日摘要和下方列表，不移动格子、不改变热力图起止日期。每天自然推进一个日期格，显示窗口按固定宽度容纳历史。
17. 趋势图点选同样只更新选中状态、当日摘要和下方列表，不移动柱形、不重新加载日期范围；只有明确的前后导航或周/月切换调整趋势范围。
18. 更新时间采用北京 / 上海时区 UTC+8，展示清晰日期和时分秒，不直接显示 UTC ISO 字符串。
19. 未指定手动 USD/CNY 时采用最新公开日参考汇率，显示来源与公布日期；手动值优先，清空或 0 恢复自动。断网使用有效缓存并注明，暂无有效值时不虚构人民币费用。实现边界见 [自动汇率](../docs/exchange-rate.md)。
20. 所有来源在设置显示默认候选本地文件/目录，逐项注明已发现/未发现。可点击查看完整路径、更改路径、选择文件或文件夹、恢复默认；自定义路径独占替代默认候选，缺失时不回退读取默认位置，修改和恢复不删除历史。
21. 仅支持真实同步实现的 Cursor / TRAE 国际版提供手动凭据连接、同步、解除；这是实验性私有 Dashboard 接口，不是官方 OAuth，不自动读取浏览器 Cookie。其他来源提供接入说明或真实用量导入，不能靠授权按钮或积分虚构 Token。

现有 HTML 交互预览仍为演示数据，不代表本机用量。v0.4.0 的 56 个入口仍分为 28 个原生明确格式解析入口、3 个同步缓存解析入口（Cursor、TRAE TraeCode、Antigravity）及 25 个真实用量导出入口；Cursor / TRAE 的主动同步是这三个缓存入口中的附加通道，不重复计数。全部保留规范/API 用量导入。解析格式实现并不证明本机安装了对应软件或已取得真实会话。真实机器验证、最新软件/模型计数与未完成项见 [开发状态](../docs/development-status.md)，格式和保守限制见 [扩展适配记录](../docs/extended-adapters.md)。最新 EXE 体积以构建报告为准，不得把预览金额、模型分配或汇率当作真实采集值。

## 2. 产品定位与展示规则

Windows 中文桌面仪表盘，安静常驻托盘。用户能快速看到消耗多少、哪个软件产生、实际用了什么模型、按可用价格估算值是多少。

### 有用量才显示

- “发现安装”不触发看板展示；来源验证成功且取得第一条有效用量后，才进入可展示集合。
- 软件用量表仅显示当前所选日期/范围中产生有效用量的软件。历史用过但今天未使用的软件，在今天隐藏，切到有历史用量的日期时出现。
- 不展示未接入软件的占位行，也不展示“已接入 X/Y”之类暴露隐藏软件的分母或逐个警告。
- 标注“仅统计可获取的用量”，避免把部分来源汇总误认为所有软件的完整账单。
- 用户进入设置的来源状态后可查看全部来源路径、可用适配器、连接或导入说明；这是配置入口，不是消耗排行。
- 没有有效数据时展示空态和“添加数据来源”，不填充一串 0 Token 软件。
- 暂时采集失败的软件如有有效历史记录，仍显示对应历史值与更新状态；不因临时断线丢失历史或把历史当成零。
- 当前用户、已配置来源、可获取历史为默认范围；WSL、其他系统用户和远程来源需要明确配置。

## 3. 信息架构与视觉

| 入口 | 内容 |
| --- | --- |
| 托盘悬停 | 今日 Token、所选币种费用、有效软件数和更新时间 |
| 托盘单击 | 打开主窗口，默认趋势图；不弹出独立面板 |
| 总览 | 精炼统计卡、默认趋势图/紧凑热力图、按选中日期联动的软件与模型列表 |
| 软件 | 当前日期或周期内有用量的软件，直接展开模型；互斥 Token 分桶、缓存占比和用量占比条 |
| 模型 | 同一日期口径下跨软件按模型与提供商汇总，展示来源软件及占比 |
| 设置 | 币种、自动公开汇率与手动覆盖、两图颜色、逐来源路径与连接管理、参考价目更新；启动、完整联网发现与隐私管理继续按设计推进 |

主窗口建议默认 1120 × 760 DIP，可缩放，主体内容支持滚动；设计预览为展示完整内容而向下展开。Windows 风格的克制圆角与层次，支持浅色/深色、高 DPI、键盘和屏幕阅读器。数字对齐，状态有文字说明。

保留“总览优先”和“列表优先”两个设计选项，推荐总览优先。前者突出图表与日期联动，后者突出软件列表与模型归属。

软件品牌图标为 27 DIP，窄屏缩为 22 DIP，保持原始比例与品牌配色。图标和软件名同时展示，模型子行继续以名称和提供商区分；品牌图标不受图表调色影响。为深浅主题选择清晰底色或品牌原有主题变体。正式软件随安装包携带已核实素材，来源未取得图标时使用通用软件图形；图标加载失败仍显示软件名称。

后续联网发现的新品牌图标经官网身份核实后进入本地缓存；断网沿用缓存，获取失败使用通用软件图形。只有取得有效用量的软件才在统计页展示新图标，联网候选列表位于设置。

旧预览素材：Claude Code、TRAE、WorkBuddy、DeepSeek Harness、OpenCode 使用官网图标；Codex 使用 LobeHub 图标库的 Codex 品牌图标。v0.3 原生 EXE 已内置 38 个品牌图标资源，其中本轮 26 个来自 tokens 参考仓的客户端素材，均等比转换为 64px PNG，部分同品牌入口复用图标。原始素材、资源摘要与来源记录位于 `design/assets/brands/sources.json`，MIT 归属保存在 `vendor/LICENSE.tokens` 和第三方声明。38 个图标不代表 38 个本机已采集软件；Reasonix 等没有已核实专用素材的来源保留通用软件图形，不恢复首字母占位。程序显示已有品牌图标不依赖运行时联网。

## 4. 日期与联动规则

共享两个明确的状态：顶部汇总范围 summaryRange、下方选中日期 selectedDay。它们职责不同，界面同时显示范围名称和单日日期，不把两种口径混在一起。

| 操作 | 顶部总计 | 图表 | 下方软件与模型 |
| --- | --- | --- | --- |
| 每次启动 | 恢复上次范围，首次为今日 | 显示截至今天的趋势图，不恢复旧图表类型或历史定位 | 清除旧单日选择，显示对应范围用量 |
| 切换今日/近 7 天/本月/全部 | 切换所选范围 | 保持当前图表类型及其明确标注的范围 | 清除单日选择，显示新范围汇总 |
| 点击热力图某日 | 保留所选周期总计 | 标记该日期；网格位置、尺寸与起止日期固定 | 立即显示当天软件、模型与费用 |
| 点击趋势图某日 | 保留所选周期总计 | 标记该日期；柱形位置、日期范围与导航定位不变 | 立即显示当天软件、模型与费用 |
| 热力图/趋势图互切 | 不变 | 保留同一个所选日期 | 保留当天统计 |
| 返回周期汇总 | 不变 | 清除选中日期 | 回到顶部周期的汇总 |
| 点击软件 | 不变 | 保留日期上下文 | 软件详情按同一天或周期展示模型 |
| 切换币种或颜色 | Token 不变 | 更新金额或颜色 | 日期选择与 Token 不变 |

选中后表头明确显示例如“2026-08-25 · 单日 · 4 个有用量软件”，并出现“返回本月汇总”。热力图下的摘要显示准确 Token、费用、数据状态。选中零消耗日期时，软件表为空；选中缺失日期时显示“数据缺失，无法确认”，不能显示成 0 消耗。

“全部”从最早可用历史记录累计至当前时间，包含导入的历史数据，不受图表可见日期范围限制。仅代表已采集记录，不推断接入前或缺失时段的消耗。选择某一天后显示“返回全部汇总”；返回后恢复全部软件与模型的历史累计。托盘悬停固定显示今日摘要，不受主窗口历史单日选择影响；打开主窗口时先展示趋势图。

今日按 Windows 配置时区 00:00 起算，原始事件时间存 UTC；跨午夜更新、夏令时和时区切换按当地自然日重新聚合。日期或时间未知的记录独立归档，不强行记到今天。

## 5. 热力图与趋势图

### 每日热力图

- 用更多日期铺满横向空间，最多展示截至今天最近 365 个自然日；精确起止日期和实际显示天数始终可见。
- 日期轴固定由今天和窗口宽度计算，独立于 selectedDay、趋势定位日期和数据中最早日期。点选任一格不滚动、不重新锚定、不重排网格；跨午夜才自然推进今天的格子，窗口缩放时可调整可见历史长度。
- 参考 GitHub 的紧凑密度，色块约 11 × 11 DIP，行高约 12 DIP，列间距约 3 DIP；七行网格高约 102 DIP，不扩大色块填空白。
- 按周为列、星期一至星期日为行，标注月份和一/三/五；横向占满面板，列数依据宽度调整（约 14–53 周），窄屏保持横排并展示较短范围。
- 未采集历史只显示空白中性色小方格，无点纹或斜线；图例、日期提示及选中摘要标注未采集，与已确认的零值区分。选择后显示“Token 与费用未知”，不虚构历史值。
- 普通鼠标和键盘可以选择日期；触屏另提供原生日期选择器，避免为触屏把小方格扩大。
- Token / 费用切换共用同一个当前指标状态，切到趋势图时沿用，避免两个图表暗中用不同单位。
- 数量以主色的四档色阶表示，零值与未知使用不同中性色。费用只有部分定价时颜色表示已定价部分，摘要注明缺口；全部未定价时按未知状态显示。
- 分档基于当前图表中可用正值的四分位数；同一数据快照内阈值固定。实际产品图例可查看数值阈值。
- 悬停、键盘聚焦可查看日期和准确值；点击立即联动软件表。选中描边与配色独立，不能仅靠颜色表示选中。

### 每日趋势图

- 图表切换中排在热力图之前；每次启动及通过“打开主窗口”进入总览时先展示趋势图。同一窗口内仍可切换热力图，改日期、币种、颜色或进入设置不强制切回趋势图。
- 每个可选择的日期对应一个柱形，单位明确为 Token 或当前币种。
- 默认近 7 天，也可查看导航定位所在月份，始终显示确切时间范围。独立导航状态 chartEnd 由前后按钮或周/月导航控制；selectedDay 不修改 chartEnd，不触发移动或加载另一日期范围。
- 悬停查看准确值，点击日期与热力图共用 selectedDay。点击只改变选中标记、摘要和下方软件/模型列表，柱形及日期命中区域固定。跨图切换保留选中日期；热力图始终截至今天，不跟随趋势图的历史导航移动。
- 日数较多时轴标签适度省略，但每个日期仍可查询、选择；窄屏将月份拆成周段保持可点击，不把一整月日期挤成不可点的细线。
- 缺失不画成零柱，零值与缺失分别标明。费用趋势只汇总有可靠计价的部分。

## 6. 软件 → 模型统计

软件用量采用“软件分组 + 模型列表”，总览和软件页均默认完整展开，不需要先点进软件才能比较模型。软件组头显示名称、模型数量、Token 小计与费用小计；组内每个实际模型独立一行，缩进展示模型名称、提供商、该模型 Token 与预估费用。软件组按小计 Token 降序，组内模型也按 Token 降序。

v0.3 参考 tokens 的 `ProfileToday`、`ProfileModels`、`TokenBreakdown` 和贡献日历布局，保留原生 Win32 渲染：统计卡概括 Token、估算费用和有用量软件；下方展示普通输入、普通输出、缓存读取、缓存写入、推理及未分类的互斥分桶，并注明缓存读取占总输入的比例。软件占比以当前所选日期/范围总 Token 为分母，模型占比以该软件小计为分母；跨软件模型页的模型占比仍以所选范围为分母，来源软件占比以该模型小计为分母。占比条只辅助比较，不生成额外用量。

费用旁显示“API 估算”“手动费率估算”“已有估算”及已保存的价格来源；混合来源与未定价部分分别提示。旧记录没有来源信息时保留“已有估算”，不替它编造来源或宣称实际付款。仅有总量的记录进入“未分类”，仍展示实际 Token，费用保持未知。

列表优先布局与软件页额外显示各行的输入/输出；模型 ID 可通过提示或详情查看。未知模型保留独立行，费用显示未定价。模型行继承同一软件与日期范围，点击热力图或趋势图日期后，同时更新软件小计和每一行模型值；没有用量的模型行随之隐藏。

软件小计只是分组汇总，不作为额外用量再累计；所有模型行之和应与软件小计一致。进入软件详情仍可查看更多输入、输出、缓存和价格依据，独立模型页仍用于跨软件对比。

模型页可跨软件汇总相同模型，但至少以“提供商 + 实际模型 ID + 已知版本/计价身份”区分。不同平台的同名模型、不同快照不静默混并；同名但身份不明的条目保留独立来源。

每次调用保留：软件/实例/环境、会话/请求身份、事件时间、实际模型 ID、显示名称、提供商、请求模型/路由档位、输入输出缓存、价格版本、模型归属依据。

- 首选响应/调用记录报告的实际模型；官方用量接口按模型汇总的记录作为明确来源使用。
- “当前配置的模型”只表示配置，不能反推历史。用户手工修改显示别名不改实际模型身份。
- 软件只暴露 Auto、快速、均衡等模式且未披露底层模型时，显示“Auto · 底层模型未知”，依然计入软件总 Token，不按软件品牌猜测模型。
- 子智能体在同一任务中换模型时，各次真实调用归到对应模型；软件总计仍合并，不漏掉子调用，也不把同一请求重复计入多个软件。
- 模型别名无法证实映射时不自动合并；无法定价时保留 Token、费用未定价。

### 当前设计的数量与支持边界

v0.3 合并清单有 56 个来源入口：28 个原生明确格式解析器、3 个已有同步缓存入口和 25 个真实用量导出入口；明细见 [接入覆盖设计](support-coverage.md)。参考 README 的 41 个客户端对应 27 个原生格式、3 个已有缓存和 11 个需导出客户端，DeepSeek Harness 是原有清单中另外已实现的原生来源。CodeBuddy 仍缺本机真会话，Antigravity CLI 等来自参考结构核实，并非全部厂商公开稳定格式；云端、加密或无 Token 缓存不能标为自动接通。实际软件与模型数由有效记录决定，最新实测见开发状态，不以解析入口数或价目记录数代替。旧预览仍为 6 个软件、7 个已知示例模型及 1 类 Auto 未知模型，不能作为真实统计。

统计不使用固定模型白名单：现有适配器能从受支持格式取得真实 Token、调用时间和模型 ID 时，新模型自动产生统计行，无需把名字加入编译清单。模型归属能读取、Token 能统计、价格能匹配是三个独立能力；没有价格时保留用量并标记未定价。对全新软件或未知格式，仍需核实和新增适配器，不能宣传“任意软件、任意模型全部已支持”。

### v0.4.0 来源路径与连接

全部 56 个设置卡片逐行展示本地候选及“已发现 / 未发现”，保留软件名、实际记录数与采集状态。长路径省略显示但可点击原生详情/编辑；卡片按路径条数和连接说明动态增高。自定义路径一次只替代该来源的默认候选，不叠加扫描；配置缺失时明确未发现，恢复默认不删除数据库历史。

只有 `cursor` 和 `trae-code` 显示凭据授权功能。用户手动输入自己的连接凭据，Windows 当前用户 DPAPI 加密保存于本机，程序不读取浏览器 Cookie、不把凭据写入用量数据库或导出。私有 Dashboard 接口具有版本/账户限制，不宣传官方 OAuth 或完整账户历史；当前默认同步最近 30 天。其他来源保留本地格式说明和真实导入，不生成无效授权入口。

“凭据已保存”只表示本机配置，尚未验证服务器；同步中、成功、失败和授权过期分别显示。有已存凭据时可同步/解除，失败或过期可重新授权。完整分页成功后才原子发布本地用量缓存并按实际 Token 解析入库；有效空结果不生成用量，网络/认证/分页失败或取消保留旧缓存。解除连接移除本机凭据，已入库用量继续保留。具体接口与边界见 [连接说明](../docs/connections.md)。

连接状态仅在运行内存保存，不写入偏好文件；重启能解密已有凭据时显示“已保存，待验证”，需主动点击“同步”验证并读取远端用量。目前不自动后台同步账户；15 秒自动刷新只检查本地文件。

## 8. Token 与重复计数

- 总 Token = 输入总量 + 输出总量 + 未分类总量；输入总量包含缓存读取/写入。仅报告总量的来源保留未分类，不虚构输入 / 输出；适配器先核实包含关系，不能把所有字段直接累加。
- 推理 Token 若是输出子集，只作细分，不二次相加。未知包含关系保留原始口径并标记。
- UI 分桶为普通输入 = 输入总量 − 缓存读 − 缓存写，普通输出 = 输出总量 − 推理，再单列缓存读、缓存写、推理和未分类；这六项之和等于总 Token。1 小时缓存写入是缓存写入的子集，不能再加进总量。
- 流式最终用量只记一次；累计计数器按有效增量处理，识别会话重置、轮转和回退。
- 实际产生用量的重试分别统计；同一事件重放、重复导入、软件重启不增加总量。
- 稳定请求 ID 优先去重；没有可靠身份时不把重叠镜像来源都纳入总计。
- 嵌套运行多个智能体时，每次物理调用只计一次。保留主调用软件和子调用链，但软件排行采用明确的一种归属口径，不同时记父软件和子软件两次。
- Token 跨模型相加代表记录数量之和，不代表同等计算、价值或订阅额度。

## 9. 币种与费用

设置入口为“显示币种”：美元 USD / 人民币 CNY。切换立即应用到总计、软件表、模型表、详情、图表轴与提示、热力图摘要、托盘悬停提示。Token、日期和原始记录不变化。

记录保留原始金额与币种；汇总时按同一显示汇率快照转换，不反复修改原始数值。计算采用十进制定点精度，显示时四舍五入；舍入误差不用于改动 Token 或原价。

正式设置提供汇率来源、更新时间和自动/手动汇率；离线使用上次有效汇率并注明。有金额但缺少必要汇率时不能混币种相加，分开显示或标为无法换算。导出包含原币种、原金额、显示币种和汇率版本。

费用分开标识：官方报告值、模型单价估算、订阅折算参考、未知。主看板默认“预估费用”；订阅折算不等于额外扣费。未知模型费用不当作零；部分已定价时明确显示“已定价部分”和缺失提示。

v0.3 已实现公开参考价目自动匹配及用户主动联网更新。三源为 LiteLLM、models.dev、OpenRouter，另有小型 Cursor 官方核验表；内置 2,011 条“提供商 + 模型 + 价目来源”记录，含同一模型的多来源报价，**不是 2,011 个不同模型，也不是本机用过的模型数**。来源、获取日期、匹配键及价格版本可追溯；联网只获取公开 JSON，不上传本地用量。详见 [公开费率参考与计费口径](../docs/pricing-reference.md)。

费用依据真实记录的提供商、实际模型 ID、输入/输出/缓存分类及适用上下文档位计算标准 API 价格估算，不等同于智能体订阅实付或余额。输入已含缓存、输出已含推理，各桶只计价一次；缓存读写、5 分钟/1 小时写入及明确差异推理价格分开处理。长上下文按已核验的整次请求提示词长度选择适用档位，而非只对超出部分加价。没有可信模型、分项、所用缓存类别费率或安全计算条件时保留未定价。

手动费率按软件、实际模型和提供商优先匹配尚未定价记录；自动选中的完整价目、来源及档位固定到历史记录。下载新价目或新增手动价格只补尚未定价用量，不静默覆盖已定价历史。显式重新估算仍属后续设计，当前不提供批量改写历史价格。日志未记录的 Batch/Flex/Priority、地区、合同、套餐折扣、搜索/工具及音视频账单项目不假定可精确还原。

预览的 1 USD = 7.10 CNY 为固定虚构示例，不代表当前汇率或真实账单；美元 8.42 对应人民币 59.78（显示舍入）。

## 10. 颜色设置

- 热力图主色与趋势图主色为独立设置，可使用颜色选择器；即时预览并保存。
- 热力图由所选主色生成连续色阶；趋势图采用独立主色。不能把整个软件界面、警告或选中控件一起改色。
- 恢复默认清除自定义颜色，重新跟随系统浅色/深色配色。
- 自动调整极浅/极暗颜色明度以保持可见性；零消耗、未知日期、键盘焦点、选中描边仍保持可辨认。这些主题与可访问性细节继续作为完整设计验收目标。
- 调色只改变表现，不改变阈值、排序、日期、金额或数据值；切换币种不改变 Token 色阶。

## 11. 托盘、启动与关闭

原生悬停提示保留简短三行：今日 Token、当前币种预估费用、更新时间与有用量软件数；长度按 Windows 限制处理。没有未接入软件的名字、占位或分母。

不再提供独立托盘面板。单击托盘图标直接打开主窗口，默认趋势图；悬停只显示今日摘要，币种与主窗口一致，不受历史日期选择影响。

右键提供打开、刷新、暂停/恢复采集、设置、退出。关闭主窗口或 Esc 默认隐藏到托盘，后台继续统计；退出菜单停止程序。开机启动仍是后续由用户主动启用的设置目标。Explorer 重启后恢复托盘图标，睡眠 / 多屏等完整实机验收继续推进；托盘图标是否显示在外侧由系统和用户决定。

## 12. 数据架构与异常

针对单个 EXE 不超过 10MB 的新要求，技术路线调整为 C++ / Win32 原生界面、Windows 系统图形与网络 API、编译进程序的 SQLite。首个目标平台为 Windows 10 / 11 x64；正式选择先通过含托盘、数据库、解析和联网能力的 Release 体积基线验证，具体见 [开发准备与体积计划](development-plan.md)。分层为来源发现/适配 → 标准化/去重 → 存储/聚合 → 窗口/托盘，采集不依赖窗口是否可见。

当前每 15 秒检查已知本地来源目录，不触发远端账户同步；Codex / Claude Code 有持久增量检查点，新采集器目前通过稳定身份去重，并非全部实现逐文件增量。后续配合目录通知与低频补查，避免每秒全盘递归；远端来源退避，不过度请求。建议实体：Source、SourceInstance、UsageEvent、ModelIdentity、ImportCheckpoint、PriceVersion、FxSnapshot、Estimate、DailyAggregate、UiPreferences。联网扩展实体为 AgentCatalogEntry、DiscoveryCandidate、AdapterManifest、IconCache、OnlineLookupRecord；来源采集与联网查询互相独立，断网不阻塞本地统计。

用量数据库只保存计量与身份元数据，不保存提示词、回复、代码正文或连接凭据；解析涉及完整日志时在内存提取字段，诊断脱敏。v0.4.0 手动连接凭据使用当前 Windows 用户 DPAPI 加密到独立本机文件，不从浏览器或发现过程扫描 Cookie/密钥。数据保留与清理管理继续作为完整设计目标。

异常要区分：导入中、真实零消耗、数据缺失、部分覆盖、更新失败、未定价、无法换汇、暂停、离线。保留最后成功数据并注明更新时间；没有新增事件不等于采集失败。

性能目标仍需完整实测：空闲平均 CPU 低于 0.5%、小规模常驻内存低于 100 MB、主窗口唤起低于 150 ms；本地记录可见延迟当前受 15 秒检查周期影响，目录通知完成后再验证通常 5 秒内可见。百万级历史导入不能阻塞窗口与托盘。

完整设计仍包含常用 / 自定义日期、启动设置、深浅主题和完整可访问性，以及新软件/模型目录发现、按需搜索、动态品牌图标缓存和可信适配器更新。当前联网已实现主动更新公开参考价目并补全未定价记录；**联网搜索新智能体并自动接入尚未完成**，也不会凭搜索结果自动取得用量。完整软件发现服务、搜索部署和适配器更新信任机制继续按 [联网发现与更新设计](online-discovery.md) 推进。

验收重点：

- 未接入软件在看板与托盘完全不出现；新有效记录触发出现；无当日用量的历史软件在当日列表隐藏，但历史日期可查看。
- 全部来源只在设置展示配置；候选路径逐项标识存在与缺失，自定义排他替代、缺失不回退、恢复默认不丢历史；长路径可查看完整内容。
- 只有受支持来源显示授权；凭据保存与服务器验证区分，DPAPI 当前用户保存可解除，失败/过期可重连；分页成功才替换缓存，空同步无占位用量，失败保留旧值。
- 热力图与趋势图点选同一日期得到相同的软件/模型/金额；互切保留日期；返回周期与改周期均正确恢复汇总。连续点选任一图的日期都不改变该图日期命中坐标、起止范围或图表位置；热力图只随今天/窗口宽度推进，趋势只随明确导航调整。
- 零消耗与缺失日期有不同空态；未知模型和未定价不猜测、不当成零。
- 软件内模型和跨软件模型总计与原始请求可对账；父子软件、镜像来源、重放与轮转不重复。
- 普通输入/输出、缓存读写、推理和未分类分桶总和等于总 Token；软件及模型占比分母随所选日期/范围正确变化，1 小时缓存写入不二次相加。
- 同一软件的不同模型在列表中直接分行；模型行 Token 之和等于软件小计，软件小计之和等于对应范围总计；切换日期、币种后分组和明细同时更新。
- “全部”累计所有已采集历史；软件和模型分项可对账，点选单日再返回全部正确恢复；托盘今日悬停不受主窗口范围和历史选日影响。
- USD→CNY→USD 不累计舍入误差；全界面与托盘币种一致；缺汇率不混加。
- 两图颜色独立、持久化、可重置；极浅色/深色有可见性；调色不改变数据。
- 深浅色、125%/150%/200% DPI、键盘、多屏、Explorer 重启、睡眠恢复与跨日正常。
- 关闭窗口继续采集，退出停止；大量导入与格式错误不使界面无响应。
- 新智能体联网发现后仅进入来源管理候选，取得真实有效用量后才进入统计；兼容现有格式可自动匹配，不兼容时显示待适配。
- 新模型凭记录中的实际模型 ID 自动出现；联网查到的支持模型列表不能反推历史用量；未匹配价格时显示未定价。
- 图标、目录、报价与适配器可分别更新；断网沿用有效缓存，失败不损坏历史；报价更新不静默改写历史估算。
- 参考 API 价目按提供商隔离，明确上下文档位按整次请求选择；手动与自动价目来源可辨，未知不变零，已定价历史在联网更新与重启后仍使用原费率。
- 未知软件的联网搜索去重并退避；只发送必要名称、版本、模型 ID，不上传本地日志、提示词、代码、凭据或完整软件清单。
- 适配器更新验证版本与来源，失败可回退；不得直接执行搜索结果中的代码。详细验收见 [联网发现与更新设计](online-discovery.md)。
- 完整 Release / x64 的 EXE（含最终资源和签名）不超过 10,000,000 字节；在受支持的 Windows 上验证便携运行，另报数据与缓存占用，不能漏打包必要依赖来虚报程序大小。
