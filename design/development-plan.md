# 开发准备与 10MB 发布目标

版本 v16 · 2026-10-09 · v0.4.0 增加 56 来源路径管理和 Cursor / TRAE 国际版实验性手动凭据同步，保留北京时间与自动公开汇率；产品仍定位为 Windows 用量统计工具。

## 1. 发布体积与运行边界

Windows 10 / 11 x64 为首个目标平台。便携版发布单个 `TokenScope.exe`，文件大小上限按十进制 10MB，即 10,000,000 字节执行；Release 构建、最终资源和签名全部完成后检查。工作目标为留出余量的 8MB 以内，实际结果以编译测量为准，不能把估算当作已达标。

完整程序运行所必需的自有代码、解析器和数据库引擎计入 EXE；不通过外置必要 DLL、首次下载大型运行库或启动器隐藏真实程序体积。依赖 Windows 自带系统组件，面向支持的系统版本验证直接运行能力。

运行产生的用量数据库、配置、诊断记录以及联网图标 / 元数据缓存另存 `%LOCALAPPDATA%\TokenScope\`，会随使用增长。这些是用户数据，分别显示占用、提供保留期限与清理；程序文件小于 10MB 不代表历史数据永远小于 10MB。

## 2. 实现路线

| 部分 | 选择 | 体积与维护原则 |
| --- | --- | --- |
| 语言与窗口 | C++，Win32 原生窗口与控件 | 不随产品打包 Web 渲染引擎或 .NET 运行库 |
| 图形与文本 | 当前使用 Windows 自带 GDI 与 WIC | 原生绘制趋势、紧凑热力图和分组列表；使用系统字体，后续按需评估 Direct2D |
| 托盘 | Windows Shell 托盘接口 | 保留图标、悬停摘要、打开主窗口与右键菜单；移除独立面板 |
| 数据库 | SQLite amalgamation，编译进程序 | 只启用需要的数据库能力，避免大型 ORM；第三方版本和许可证可追溯 |
| 联网 | Windows WinHTTP 与系统 TLS / 证书能力 | 异步查询与缓存，不附带独立 TLS 运行库 |
| 连接凭据 | 当前 Windows 用户 DPAPI 加密的本机独立文件 | 用户手动配置，仅支持两个明确来源；不自动抓取浏览器 Cookie，不冒充官方 OAuth |
| 用量解析 | yyjson、SQLite 只读适配、Zstandard 静态解压 | 避免内嵌 Python / Node；读取 DeepSeek Harness 压缩日志，实际字段和包含关系按来源验证 |
| 图标与目录 | 压缩的内置必要素材＋可更新本地缓存 | 保留离线基础能力；联网补充素材不阻塞统计 |
| 更新 | 声明式适配规则与目录独立更新，复杂解析代码随 EXE 更新 | 避免为了插件扩展携带额外脚本运行时；代码更新可验证、可回退 |

视觉与交互沿用已确认设计，HTML 预览仅为设计参考。原生实现需要单独验证布局、键盘、深浅色和 DPI，不能把预览嵌入一个大型浏览器壳后视为完成。

必要运行库优先静态链接，以支持便携 EXE；被静态链接依赖的修复通过重新编译和发布 EXE 提供。依赖系统 DLL 是 Windows API 的正常运行基础，不纳入自有程序下载体积。

## 3. 准备项与现有环境

| 准备项 | 当前结果 / 后续用途 |
| --- | --- |
| 源码项目 | src / tests / resources / vendor / scripts；56 来源入口，28 个明确原生格式、3 个同步缓存解析、25 个真实导出来源，全部路径可更改/恢复，详见接入覆盖 |
| C++ 编译器与 Windows API 头库 | 初查未发现全局开发工具，现使用工作区 .tools 内官方 LLVM-MinGW 20261006 便携工具链；完整下载摘要已验证，不全局安装 |
| 构建工具 | scripts/build.ps1 固定 Release / x64，编译资源、优化、静态链接、检查体积与系统 DLL 依赖 |
| .NET | 当前检测到运行库，未检测到 SDK；选定原生路线不要求用户安装 .NET SDK 来运行产品 |
| 真实来源样本 | 开发时从本机已使用来源做最小范围只读验证，留脱敏测试样本，不要求上传完整日志 |
| 云端来源授权 | 仅 Cursor / TRAE 国际版已有实验性私有 Dashboard 手动凭据同步；不是真实账户全覆盖或官方 OAuth，其他来源按说明/导入，不能用通用 API Key 替代全部平台权限 |
| 联网搜索 | 正式搜索 API 或网关配置；本地统计不依赖搜索密钥，目录与缓存可以独立工作 |
| 发布签名 | 正式分发时准备签名方案；开发本地运行和体积基线无需购买证书 |

构建工具和 SDK 是开发环境，不随成品分发，安装占用与成品 10MB 目标分别管理。安装前明确所需组件和磁盘空间；不把开发工具打入用户产品。

## 4. 基础里程碑与持续验证

原生主窗口、托盘悬停、SQLite、JSON 解析、WinHTTP 与离线失败处理已建立可构建基线。后续每次 Release / x64 继续记录 EXE 字节数和依赖清单，验证不依赖额外自有运行文件才能启动。

同时验证高 DPI、中文路径、关闭隐藏、退出停止和 Explorer 重启后的托盘恢复。体积基线超过预算时先解决依赖和资源问题，再扩展全部功能；不等到最后一次打包才发现超过 10MB。

## 5. 后续实现顺序

1. 统一 UsageEvent、来源实例、模型身份、定点金额、导入检查点与去重；完成数据库和有意义的计量测试。
2. 现有明确格式继续验证更多真实版本，完善持久增量检查点与大历史性能；已有缓存、需要启用的 OTel 和规范导入不冒充自动读取全部用量。
3. 沿用总览、模型分组、日期联动、全部、币种、图标与调色。热力图固定截至今天；趋势和热力图点选都不移动或回退日期；每次打开默认趋势；托盘保留图标和悬停，取消面板。
4. 按 [接入覆盖设计](support-coverage.md) 推进合并后的 56 个来源目标的可靠原生或官方通道。所有目标已有实际用量规范导入；云端、加密和无 Token 缓存仍明确限制。
5. 接入联网目录、按需搜索、图标缓存、模型价格补全和适配更新，遵循 [联网设计](online-discovery.md)。桌面程序保持统计工具定位，不内置聊天模型或自动执行其他智能体任务。
6. 校验完整 Release 的体积、冷启动、空闲开销、百万级历史导入、跨日、重复导入、离线和故障恢复；最终签名后再次检查 10,000,000 字节上限。

## 6. 体积与发布验收

- 每次 Release 构建打印 EXE 实际字节数；超过 10,000,000 字节即发布检查失败。
- 调试符号、源码、样本、测试数据库和设计预览不打入成品；必要依赖和资源不能被漏掉来虚报大小。
- 只统计程序的 EXE 体积，同时另报首次运行数据与长期数据库 / 缓存占用。
- 基础版、完整功能版、签名版分别留测量记录；在未安装开发工具与额外应用运行库的受支持 Windows 上验证。
- 缓存和历史数据设置上限 / 保留策略，关闭窗口后以目录事件和低频补查增量统计，避免高频全盘扫描。

## 7. 当前状态

当前版本为 v0.4.0，内嵌图标、许可、SQLite、JSON、Zstandard 解压、离线参考价目与静态 C++ 库，没有首次下载运行库的启动器。本轮产物 `dist/TokenScope-0.4.0.exe` 为 2,289,152 字节，文件/产品版本 0.4.0，仅导入 Windows 系统 DLL，通过 10,000,000 字节门槛；最终十五组测试全部通过。大小、摘要与依赖见 [版本构建报告](../dist/TokenScope-0.4.0.build-report.json)，原生运行及旧数据库回归见 [开发状态](../docs/development-status.md)。上一版 0.3.1 的 2,221,056 字节仅作为历史基线。

核心、来源解析、规范导入、集成和视图检查由 `scripts/test.ps1` 执行；最新真实机器结果集中在 [开发状态](../docs/development-status.md)，不沿用首版性能或软件数量作为新版证明。第三方联网目录中的模型数不代表实际已使用模型或已采集软件数量。

当前仍是开发版。已实现三源公开价目更新、保守自动估价、手动优先与历史价目固定、自动公开日参考汇率、北京时间、逐候选路径存在状态和独占自定义/恢复。两个特定账户通道只有完整取得真实 Token 后才进入统计，空同步不造用量，失败保留旧缓存；实现与账户实测分开记录。更多来源的可靠原生 / 官方通道、自动搜索 / 适配更新、更完整的报价核验、深色 / 完整辅助功能、清理策略和干净系统验证继续推进。

当前连接状态只存在于运行内存；重启解密已有凭据后回到“已保存，待验证”，用户主动点击“同步”。15 秒检查仅针对本地文件，尚无后台远端自动同步。
