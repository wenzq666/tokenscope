# 联网发现与更新设计

版本 v16 · 2026-10-09 · 完整新软件发现/搜索/适配器更新仍未完成；v0.4.0 已实现公开价目与汇率更新、56 来源路径管理，以及两个特定来源的实验性凭据同步，不能把这些局部能力称为整套联网发现已完成。

## 当前实现与本设计的关系

- 公开价格：LiteLLM、models.dev、OpenRouter 主动更新，自动汇率使用 Frankfurter / ECB；离线保留有效缓存，历史 USD 价目固定。
- 来源配置：56 入口显示默认候选路径及逐项发现状态，自定义路径排他替代默认、可恢复且不删除历史。仅受支持格式中的真实用量进入统计。
- 特定账户同步：仅 Cursor 与 TRAE 国际 IDE / SOLO 手动提供凭据，经实验性私有 Dashboard 接口读取用量；非官方 OAuth，不自动抓浏览器 Cookie，Windows 当前用户 DPAPI 加密本机凭据。完整分页成功才发布缓存，空结果无占位用量，失败保留旧缓存；默认最近 30 天，不宣称全量历史。见 [连接说明](../docs/connections.md)。
- 同步时机：连接状态仅在运行内存保存，重启已有凭据回到待验证，由用户点击“同步”；没有后台远端自动同步，15 秒刷新仅检查本地文件。
- 未完成：自动搜索全新智能体、目录身份核验、动态图标获取、通用云账户连接、可信适配器更新与自动格式适配。下面相关流程仍是完整设计需求。

## 1. 功能目标与边界

未来出现新智能体或模型时，联网补充软件身份、官网、图标、模型信息、价格及用量来源，再与本机来源和实际用量匹配。采用“联网目录 + 本地采集器 + 可更新适配器”的结构。

联网搜索不产生本机 Token 数据，不证明用户使用过某模型。真实统计仍来自本地日志 / 会话数据库、来源明确的用量接口或导入文件；公开官方接口与实验性私有 Dashboard 通道分别标注。仅取得有效用量后进入总览、模型列表、趋势图、热力图和托盘；只找到官网或图标时保留在来源管理。

本功能扩展初始 26 个产品 / 平台和 12 个模型家族，不设置固定数量上限；不能承诺任何未来产品都立即可读，需要按实际版本验证。

## 2. 三个模块

| 模块 | 职责 | 不承担的工作 |
| --- | --- | --- |
| 联网目录与搜索 | 软件 / 模型身份、官网、图标、文档、价格与适配规则元数据 | 不推测用户用量，不扫描或上传聊天正文 |
| 本地采集器 | 发现来源，读取真实用量，标准化、去重和保存 | 不把支持模型列表、积分或请求数当作实际 Token |
| 适配器更新 | 提供版本识别、格式解析、字段映射、计量口径与价格身份匹配 | 不直接运行搜索结果或网页提供的任意代码 |

本地统计与联网模块独立运行。断网、搜索未配置、目录服务失效，都不能中断已有来源的读取或历史查询。

## 3. 联网目录

软件条目保存：稳定 agentId、名称与别名、官网与已核实域名、品牌图标及来源、Windows 识别规则、入口 / 环境类型、支持版本、已验证用量来源、所需授权、适配器 ID / 版本、来源证据、核实时间和目录版本。

模型条目保存：提供商、实际模型 ID、显示名称、模型家族、可证实别名、版本与计价身份、价格条目引用、来源与核实时间。供应商模型清单只补充元数据，不能改变已采集记录的实际模型归属。

目录通过 HTTPS 分发，保留版本与完整性校验，增量更新并支持回退。已核实目录和搜索候选分开保存；新候选不能直接覆盖已核实身份。

## 4. 搜索与核实流程

1. 本地发现疑似智能体、实际用量中出现未知模型，或用户点击“联网查找”时，先查询本地目录与缓存。
2. 缓存无法匹配时，调用搜索服务；查询只包含必要的软件名、版本或模型 ID。搜索接口可替换，不把功能绑定到某一个供应商。
3. 优先核实官网、官方文档、官方代码仓库及发布信息，提取品牌图标、模型元数据、报价与用量来源文档。
4. 软件身份结合名称、发布者 / 签名、产品 ID、路径特征和版本判断；不能仅因同名就匹配。未知模型别名没有证据时不自动合并。
5. 找到兼容且已验证的适配器后，在声明的来源范围内尝试只读采集；需要云端授权的来源在设置中配置。
6. 取得第一条有效用量后加入统计；没有可靠来源时保留“发现，待配置 / 待适配”，不生成零值记录。

如使用模型辅助整理搜索结果，输出必须包含证据来源并遵循目录结构约束；不能以模型回答代替真实用量、官方价格或适配器验证。

## 5. 图标获取与缓存

从核实后的官方资源获取图标；优先明确的品牌图标，网站 favicon 可作后备。保留原始比例、主题变体、来源、更新时间和内容摘要。下载后检查格式与尺寸，转换为可展示的本地素材，限制资源大小与外部引用。

按 agentId 缓存并复用，界面绘制不临时发起网络请求。断网继续使用已有图标；没有素材或加载失败使用通用软件图形并保留名称。新图标不会让没有用量的软件自动出现在统计页。

## 6. 新模型与费用

实际用量中的新模型 ID 自动生成模型行，联网随后补充显示名称、家族和价格。不同提供商、不同版本、无法证实的别名分别保存；Auto 未披露真实模型时仍归入未知模型。

价格从官方来源匹配，保留模型、提供商、生效区间、币种、输入 / 输出 / 缓存分类、价格条件和核实时间。无法确认的报价不投入自动估算；有 Token 无报价时标为未定价，部分报价可用时显示已定价部分。

新价格不静默覆盖历史估算。历史费用保留原价格与汇率版本，用户主动重新估算时产生新估算版本。USD / CNY 切换继承主设计规则，不修改原始用量或原始币种。

## 7. 适配器更新

适配器声明来源类型、支持软件版本、读取范围、数据格式、字段映射、Token 包含关系、实际模型依据、增量检查点、去重规则与所需授权。

已有解析器支持的格式，可通过经过验证的声明式规则新增路径和字段映射；新格式或新计量语义则需编写、测试并发布适配器。字段存在不等于含义相同，不能只根据字段名称自动累加。

更新清单具有版本、发布来源、完整性与签名校验、宿主兼容要求和回退版本。更新先验证再启用；失败沿用旧适配器与历史数据。联网网页或搜索结果中取得的程序不直接安装执行；适配代码通过受控更新渠道发布。

## 8. 设置与交互

完整设计计划新增“联网发现与更新”，除上面列明的已实现部分，以下开关、搜索与适配器更新均为后续配置项：

| 入口 | 行为 |
| --- | --- |
| 联网发现开关 | 控制目录检查和自动按需搜索；关闭后已有本地采集与缓存继续可用 |
| 检查目录与适配器更新 | 手动检查目录、已验证规则及兼容适配器，分别显示更新时间和结果 |
| 联网查找新智能体 / 模型 | 按用户输入查询候选；选择本机匹配项或配置官方来源 |
| 更新图标与模型价格 | 更新元数据和素材，保持原始记录与历史估算版本 |
| 搜索服务配置 | 配置可替换的搜索供应商或查询网关，明确是否已可用 |
| 来源管理 | 显示发现、待核实、待配置、待适配、已采集或更新失败等状态；不在总览增加无用量占位 |

初始建议：目录自动检查启用，未知来源自动搜索提供独立开关并默认关闭；手动搜索由明确按钮触发。用户启用自动搜索后，对新未知来源按需查询，不持续全网爬取。界面说明必要查询字段，不增加反复弹出的确认流程。

启动时异步检查目录，24 小时内不重复自动检查；未知名称 / 模型 ID 查询去重，失败退避，默认 7 天内不重复自动查询同一个未解决条目。手动重试可绕过缓存。以上为可调整初始策略，不能阻塞主窗口或托盘。

目录更新、搜索、价格核实和适配器更新分别显示结果；搜索失败不能标为采集失败。新智能体的真实首次用量触发出现，不因每次搜索命中重复通知。

## 9. 服务部署与数据

发布给多人使用时，搜索服务可由后端代理，避免把共用搜索密钥放入安装包；个人部署可由用户配置自己的搜索凭据，并保存在 Windows 凭据存储。已核实目录可通过独立目录服务分发，不要求用户配置搜索接口才能使用已有适配器。

目录与搜索请求只发送必要的软件名称、版本、公开标识与模型 ID，不发送用户名、本地文件路径、完整安装清单、提示词、代码、日志原文或密钥。用户主动配置的账户连接则只向该来源固定的用量端点发送必要认证信息，不把连接凭据交给搜索或价格服务。云端用量授权与搜索凭据分开管理。

建议本地新增实体：AgentCatalogEntry、DiscoveryCandidate、AdapterManifest、IconCache、OnlineLookupRecord。查询记录仅保存查询键、结果来源、更新时间、缓存期限与错误状态；用量仍进入原有 UsageEvent / DailyAggregate，防止元数据候选混入计量表。

## 10. 完成标准

- 新软件兼容现有格式：目录识别、取得正确图标、有效用量导入、模型归属和展示可贯通，重复扫描不重复计数。
- 新软件不兼容：设置显示待适配，统计页不出现占位；适配器更新后可读取支持范围内的历史数据。
- 新模型：实际 ID 自动产生模型行；联网价格未确认时保持未定价；供应商支持列表不虚构历史使用。
- 断网 / 搜索未配置：图标、目录和价格使用有效缓存，本地统计继续，失败不改成零。
- 报价与适配器更新：版本可追溯、失败可回退，历史用量不被改写、重放或重复累计。
- 自动搜索关闭后不对未知软件触发搜索；重新启用、手动查询、缓存与退避策略分别生效。
- 来源和价格无法核实时保留候选，不把搜索结果中的代码当作已验证适配器执行。

## 11. 实现顺序与参考

公开价目、汇率更新和来源路径管理已经先行落地；两个实验性 Dashboard 通道仅解决特定来源用量读取。后续继续实现软件目录更新、缓存、手动搜索与身份核实，再接入可信适配器更新，最后评估可选自动搜索。模型辅助生成复杂适配器属于后续研究，不作为首版自动接入的保证。

接口参考（2026-10-08 已核对）：[Brave Search API](https://api-dashboard.search.brave.com/app/documentation/web-search/codes) 可作为搜索供应商示例；[DeepSeek 用量字段](https://api-docs.deepseek.com/api/create-chat-completion/) 用于说明真实 API 用量与缓存字段需要映射。实际开发时重新核实接口与费用，搜索供应商尚未选定。
